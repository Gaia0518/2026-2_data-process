# 12주차 (11/19) 프로토타입: 1차 기본 연결

## 구현한 것
- 묶음 불러오기 (끌어다 놓기 / 파일 선택), 파일명 숫자 기준 자연 정렬 (2 < 10)
- 0번(배치도) 지정, 순서 변경 (끌기, ↑↓), 공통 이름 → `이름_0~n`
- 정리된 사본 ZIP + 이름표 CSV (원래 이름 ↔ 새 이름)
- 파일 순서대로 격자 자동 배열 (열 수 지정)
- 연결 화면: 이동·회전·배율 손잡이, 방향키 미세 이동, 곱하기/투명도, 여백 자르기
- 0번 배치도를 옆에 띄워 보기
- 되돌리기/다시 하기, 브라우저 자동 저장(배치 정보만)
- `project.json` 저장·불러오기 (원래 파일명으로 대조, 순서가 섞여도 복원)
- PNG 내보내기 (10~100%), 원본이 필요한 배율에서는 원본을 다시 읽음
- `tools/export.py`: 같은 규칙으로 원본 해상도 출력 (브라우저 한계 초과 시)
- 작업 시간·조정 횟수 기록 (Before/After 측정용)

## 확인한 것 (가상 원도 6장 + 0번)
- 정답 배치(`samples/synthetic/truth.json`)를 넣으면 이음매 없이 연결됨 → 회전 방향·배율·자르기 규칙 검증
- 브라우저 출력과 `export.py` 출력이 같은 크기, 픽셀 평균 차이 약 4/255 (보간 차이)
- 저장 → 새로 열기 → JSON 먼저, 이미지 나중(섞인 순서)으로 불러와도 순서·번호·변환 복원
