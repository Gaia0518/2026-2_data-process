# 13주차 (11/26) 2차: 배치 기반 배열

## 1. 도곽 모서리 지정 (완료)
- 도면마다 빨간 도곽선의 네 모서리를 클릭 → 자르기·기울기·배율 자동 계산, 도곽 바깥 여백은 숨김
- **빨간 선에 맞추기**: 모서리 근처에는 빨간 좌표 숫자(+200, 0 등)가 있어서, 모서리에서 안쪽으로 뻗은 도곽선 구간의 붉은 정도를 합산해 선 위치를 찾음. 선이 흐리면(강도 8 미만) 클릭한 자리를 그대로 쓰고 주황색으로 표시
- **기준 도곽**: 처음 지정한 도곽 크기가 기준. 다른 도면은 배율이 자동으로 맞춰짐 (스캔 해상도 차이 보정)
- 다음 모서리 자동 확대, 적용 후 다음 도면으로 이어서 지정
- 자동 배열은 도곽을 지정하면 기준 도곽 크기를 칸으로 사용
- `project.json`에 `frameSize`, `sheets[].frame` 추가 → `tools/export.py`도 도곽 바깥을 잘라 출력

### 실제 원도 시험 (남산정 7·8·11·2호)
| | 정밀 검출값과의 차이 |
|---|---|
| 모서리를 5~6px 빗나가게 클릭 → 맞추기 후 | 대부분 0~4px, 최대 6px |
| 7호 배율 | 자동 96.5% (도곽 1560×1245 → 기준 1505×1201) |
| 기울기 | 4장 모두 ±0.1° 이내로 보정 |

- 7호 아래쪽 도곽선은 빨간색이 거의 지워져 있음 → 주황 표시로 사람이 확인하도록 함

## 2. 第○號 이웃 번호로 자동 배열 (다음)
- 도면마다 도면 번호와 위·아래·왼쪽·오른쪽 이웃 번호(가장자리의 「第○號」)를 입력
- 하나의 도면에서 시작해 이웃을 따라가며 격자 위치(행·열)를 계산 → 도곽 크기 칸에 자동 배치
- 이웃 번호가 서로 맞지 않으면(예: 8호 아래가 9호인데 9호 위가 8호가 아님) 표시
- 배치도(0번)를 옆에 띄워 놓고 칸을 눌러 번호를 넣는 방식도 함께 검토

## 3. 곱하기가 까맣게 나오는 문제 (사용자 테스트, 대구 시가지 흑백 원도)
- 원인: 곱하기는 겹친 곳의 어두움이 누적됨. 흑백 스캔은 종이 모눈·얼룩이 모두 검은 점이라 2~3장 겹치면 거의 검게 됨 (바랜 컬러 원도도 갈색으로 짙어짐)
- 해결: 겹치기 **어둡게**(darken)를 기본값으로. 겹친 곳에서 더 어두운 값만 남기므로 선은 모두 보이고 누적되지 않음
- **종이 밝게**: 종이 밝기(가운데 영역 상위 15% 밝기)를 흰색으로 끌어올림 (편집기·export.py 동일)

## 4. 배치도 인식 → 확인·수정 → 자동 배열 (방식 변경)
사용자 요청: 0번 배치도에서 1번부터 끝까지 배치를 자동으로 인식하고, 사용자가 고친 배치대로 자동 배열

**흐름**
1. 원도를 처음 불러오면 배치도 인식 창이 자동으로 열림
2. 전체 도엽 수(표지의 「○○枚」)를 넣고, 0번에서 배치도 부분을 드래그
3. 자동 인식: 칸 크기·위치 → 번호가 적힌 칸 → 번호 매기기(기본: 오른쪽 열부터 위→아래)
4. 확인·수정: 빈 칸 클릭(빠진 번호 넣기), 번호 칸 선택 후 번호 고치기(겹치면 자동 맞바꿈)·빼기, 1번부터 순서대로 클릭, 칸 하나 그려서 격자 맞추기, 격자 밀기·줄 늘리기
5. 적용 후 자동 배열: 배치표의 모든 칸이 사각 틀(○호)로 깔리고, 원도는 도면 번호(없으면 파일 순서)로 제 칸에 놓임. 배치표에 없는 원도는 아래쪽에 따로

**자동 인식 방법**
- 칸 테두리는 길게 이어지고 번호 획은 짧음 → 선의 연속성으로 칸 간격 탐색
- 칸 수가 전체 도엽 수의 0.9~4.5배인 크기만 후보로 (종이 모눈·2배 크기 오인 방지), 칸 비율은 도곽 비율
- 번호는 칸 한가운데 있음 → 격자가 반 칸 밀린 경우를 바로잡음
- 칸 가운데 잉크가 많은 순으로 전체 도엽 수만큼 고름
- 한자 번호를 글자로 읽지는 않음 (브라우저에서 불가) → 순서 규칙으로 번호를 제안하고 사람이 고침

**시험 결과**
| 표지 | 칸 크기·위치 | 번호 |
|---|---|---|
| 남산정 (컬러, 2000px, 31매) | 빨간 칸 선과 정확히 일치 (80×64px) | 7·8·9호 세로, 7호 왼쪽 15호, 8호 왼쪽 16호, 9호 오른쪽 2호가 가장자리 번호와 일치. 빨간색으로 고쳐 쓴 11호 칸 1곳은 수정 필요 → 한 번 고치니 4장 모두 제자리 |
| 대구 시가지 (흑백, 1125px, 68매) | 42×33px로 제안 (칸이 작고 배치도 안에 필지가 빽빽함) | 정답을 몰라 검증 못 함. 영역 오른쪽 끝 글씨 열이 칸으로 잡히는 등 수정 필요 |

- 원도 가장자리의 이웃 번호(대구: 1호 아래 2호 아래 3호 아래 4호, 1호 왼쪽 5호)로 보면 "오른쪽 열부터 위→아래" 순서 규칙이 맞음
