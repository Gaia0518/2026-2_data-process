# 13주차 (11/26) 2차: 배치 기반 배열

## 1. 도곽 모서리 지정 (완료)
- 도면마다 빨간 도곽선의 네 모서리를 클릭 → 자르기·기울기·배율 자동 계산, 도곽 바깥 여백은 숨김
- **빨간 선에 맞추기**: 모서리 근처에는 빨간 좌표 숫자(+200, 0 등)가 있어서, 모서리에서 안쪽으로 뻗은 도곽선 구간의 붉은 정도를 합산해 선 위치를 찾음. 선이 흐리면(강도 8 미만) 클릭한 자리를 그대로 쓰고 주황색으로 표시
- **기준 도곽**: 처음 지정한 도곽 크기가 기준. 다른 도면은 배율이 자동으로 맞춰짐 (스캔 해상도 차이 보정)
- 다음 모서리 자동 확대, 적용 후 다음 도면으로 이어서 지정
- 자동 배열은 도곽을 지정하면 기준 도곽 크기를 칸으로 사용
- `project.json`에 `frameSize`, `sheets[].frame` 추가 → `tools/export.py`도 도곽 바깥을 잘라 출력

### 실제 원도 시험 (남산정 7·8·11·2호)
| | 정밀 검출값과의 차이 |
|---|---|
| 모서리를 5~6px 빗나가게 클릭 → 맞추기 후 | 대부분 0~4px, 최대 6px |
| 7호 배율 | 자동 96.5% (도곽 1560×1245 → 기준 1505×1201) |
| 기울기 | 4장 모두 ±0.1° 이내로 보정 |

- 7호 아래쪽 도곽선은 빨간색이 거의 지워져 있음 → 주황 표시로 사람이 확인하도록 함

## 2. 第○號 이웃 번호로 자동 배열 (다음)
- 도면마다 도면 번호와 위·아래·왼쪽·오른쪽 이웃 번호(가장자리의 「第○號」)를 입력
- 하나의 도면에서 시작해 이웃을 따라가며 격자 위치(행·열)를 계산 → 도곽 크기 칸에 자동 배치
- 이웃 번호가 서로 맞지 않으면(예: 8호 아래가 9호인데 9호 위가 8호가 아님) 표시
- 배치도(0번)를 옆에 띄워 놓고 칸을 눌러 번호를 넣는 방식도 함께 검토
