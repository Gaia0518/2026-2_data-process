# 지적원도 자동 연결 프로그램 개발 (제안서, 2026.11.12)

대상: 1911~1914년 지적원도 | 분할된 원도를 연구에 쓸 수 있는 연결 이미지로

## 01 왜 필요한가
지적원도는 토지의 필지 경계를 기록한 도면이다. 여러 장으로 나뉜 원도를 함께 보려면, 연구자가 국가기록원에서 자료를 내려받아 순서를 정리하고 0번 도면의 배치도를 참고해 연결해야 한다. 현재는 포토샵에서 각 이미지를 옮기고 곱하기 처리를 적용하며 경계를 맞추는 작업을 반복한다.

본 프로젝트는 이 준비 과정의 반복을 줄이는 도구를 개발한다. 파일 정리와 도면 배열은 자동화하고, 연구자는 인식 결과와 연결 경계를 확인하여 필요한 부분을 수정한다.

- 현재: 내려받기 → 파일명 정리 → 개별 배치 → 중첩 → 경계 조정
- 개선: 묶음 업로드 → 일괄 정리 → 배치 제안 → 확인 / 조정 → 저장

## 02 입력 자료
- **0번**: 표지 안의 작은 배치도. 각 도면이 놓일 위치와 번호를 파악하는 기준 (인식 후 사용자 확인)
- **1~n번**: 개별 원도. 파일 순서대로 이름을 정리하고, 공간상 위치는 배치도에 따라 결정한다. 파일 번호와 원도에 적힌 도면 번호는 구분하여 관리한다.

## 03 사용자가 거치는 열 단계
| 단계 | 도구가 처리하는 일 | 사용자가 확인하는 일 → 결과 |
|---|---|---|
| 01 원본 불러오기 | 묶음으로 불러오고 미리보기·목록 표시 | 혼입/누락 확인 → 작업 대상 묶음 |
| 02 순서 정리 | 파일명 숫자로 정렬, 0번 지정·순서 변경 | 순서 확정 → 파일 순서 목록 |
| 03 파일명 지정 | 공통 이름 + _0~n 사본 생성, 전후 표시 | 이름·번호 확인 → 정리된 원도 |
| 04 배치도 지정 | 0번 확대, 배치도 영역 선택 | 인식 영역 지정 → 배치도 이미지 |
| 05 배치 구조 인식 | 번호/위치/이웃 관계 읽어 배치안 제시 | 흐린 숫자·수정 표기 확인 → 배치안 |
| 06 원도 대응 | 배치 번호와 파일의 대응표 생성 | 순서와 번호 차이 수정 → 대응표 |
| 07 영역/방향 정리 | 여백 제외·기울기/배율 보정안 | 잘림 확인 → 배치용 이미지 |
| 08 자동 배열 | 배치안대로 한 화면에 배치 | 누락/중복/이웃 확인 → 연결 초안 |
| 09 경계 조정 | 곱하기/투명도, 위치/회전/배율, 기준점 정렬 | 도로·필지 연속성 확인 → 연결본 |
| 10 저장/내보내기 | 원본 해상도 출력, 작업 상태 저장 | 범위/해상도 선택 → 이미지 + 재편집 정보 |

## 04 결과물
| 결과물 | 내용 | 다음 활용 |
|---|---|---|
| 정리된 원도 | 공통 이름과 순서 번호를 붙인 사본 | 자료 관리 / 원본 대조 |
| 연결 이미지 | 선택한 범위와 해상도의 PNG 등 | 필지 분석 / 논문·보고서 도판 |
| 작업 정보(JSON) | 원본 파일명, 도면 번호, 위치, 회전, 배율, 자른 범위, 표시 설정 | 배치를 다시 불러와 수정 |

## 05 개발 단계
| 단계 | 구현할 기능 | 완료 기준 |
|---|---|---|
| 1차 기본 연결 | 업로드, 숫자 정렬, 파일명 지정, 수동 배치, 곱하기 표시, 이미지 저장 | 제공 원도를 연결하고 저장할 수 있음 |
| 2차 배치 기반 배열 | 배치도 옆 표시, 번호·위치 입력, 자동 배열 | 지정한 배치를 적용하고 다시 불러올 수 있음 |
| 3차 배치도 인식 | 영역 선택, 번호/위치 인식, 확인·수정 | 인식 오류를 고쳐 배치에 반영 |
| 4차 정렬/성능 | 기울기/배율 보정, 기준점 정렬, 축소 미리보기와 원본 출력 | 실제 자료 수에서 작동 |

## 06 검증
같은 원도 묶음과 출력 범위로 포토샵 방식과 비교한다: 작업 시간/반복 조작, 배치 인식/경계 품질, 용량/반응/재사용.

## 07 범위 밖
검색·다운로드 자동화, 필지 경계 벡터화, 현대 지도와의 좌표 정합, 훼손·복잡한 왜곡의 완전 자동 보정.
