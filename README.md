# 지적원도 연결 도구

데이터 연계 & 프로세스 혁신 프로젝트 (데이터기반 건축시스템 설계와 운영, 2026-2)

1911~1914년 지적원도는 한 지역이 여러 장으로 나뉘어 있습니다. 연구에 쓰려면 국가기록원에서 내려받은 원도를 정리하고 포토샵에서 한 장씩 옮겨 붙여야 합니다. 이 도구는 그 반복 작업(파일 정리, 배열, 겹쳐 보기, 저장)을 맡고, 연구자는 배치를 확인하고 경계를 맞추는 판단에 집중하도록 합니다.

> 판단은 사람이, 반복은 도구가, 결과는 다음 과정으로

## 데이터 흐름

```
입력 (사용자)              파생 (자동)                  출력 (파일)                     다음 공정
─────────────              ───────────                  ───────────                     ─────────
원도 묶음 0~n번      →     자연 정렬·이름_번호     →    정리된 사본 + 이름표.csv   →    자료 관리·원본 대조
0번 배치도 확인      →     격자 자동 배열          →    연결 이미지 .png           →    필지 분석·논문 도판
이동·회전·배율·자르기 →    곱하기 겹쳐 보기        →    project.json              →    다시 불러와 수정 / export.py
```

`project.json`은 편집기(브라우저)와 `tools/export.py`(파이썬)가 함께 쓰는 형식입니다. 형식 정의는 [`schema/project.schema.json`](schema/project.schema.json)에 있습니다.

## 실행 방법

### 편집기 (설치 없이)
1. `app/index.html`을 크롬이나 엣지로 엽니다. 깃허브 페이지를 켜면 `https://<사용자>.github.io/2026-2_data-process/app/` 링크로도 열 수 있습니다.
2. 같은 지역의 원도를 한 번에 끌어다 놓습니다. 첫 파일이 0번(배치도)이 됩니다.
3. 공통 이름(예: 남산정)을 입력하면 새 파일명이 `남산정_0 … 남산정_n`으로 정해집니다.
4. **도곽 지정**을 눌러 도면마다 빨간 도곽선의 네 모서리를 클릭합니다(왼위 → 오위 → 오아 → 왼아). 클릭한 점은 근처 빨간 선에 맞춰지고, 기울기·배율·여백 자르기가 자동으로 계산됩니다. 처음 지정한 도곽 크기가 기준이 되어 스캔 크기가 다른 원도도 같은 크기로 맞춰집니다.
5. 연결 화면에서 도면을 끌어 옮기고, 모서리로 크기를, 위쪽 원으로 회전을 조정합니다. 겹치는 부분은 곱하기로 보입니다.
6. **작업 저장**으로 `project.json`을, **연결 이미지 내보내기**로 PNG를 받습니다.

이미지는 서버로 올라가지 않고 브라우저 안에서만 처리됩니다. TIFF는 브라우저가 읽지 못하므로 JPG나 PNG로 변환해 주세요.

| 조작 | 방법 |
|---|---|
| 화면 이동·확대 | 빈 곳 끌기 / 휠 / `F` 전체 보기 |
| 미세 이동 | 방향키 1px, Shift+방향키 10px (화면 기준) |
| 미세 회전 | `[` `]` 0.1°, Shift와 함께 1° |
| 되돌리기 | Ctrl+Z / Ctrl+Shift+Z |
| 저장 | Ctrl+S |

### 파이썬 도구
```bash
pip install -r tools/requirements.txt
```
```bash
python tools/rename.py data/raw/내려받은폴더 --name 남산정 --out data/raw/남산정
```
```bash
python tools/export.py data/raw/남산정/남산정.project.json --images data/raw/남산정 --scale 1
```
원본 해상도가 너무 커서 브라우저에서 내보낼 수 없을 때 `export.py`를 사용합니다. 편집기와 같은 규칙으로 합성합니다.

### 시험용 자료
`samples/synthetic/`에는 `tools/make_samples.py`로 만든 **가상 원도**(실제 자료 아님) 7장이 있습니다. `truth.json`에 정답 배치가 있어 정렬 정확도를 확인할 때 씁니다.

## 폴더 구성

```
app/       브라우저 편집기 (HTML·CSS·JS, 외부 라이브러리 없음)
tools/     파이썬 도구 (export, rename, make_samples)
schema/    project.json 형식 정의
samples/   깃에 올리는 작은 시험 자료
docs/      제안서, 주간 기록, 발표 자료
eval/      Before/After 측정 기록
data/      실제 원도와 출력물 (깃에 올리지 않음)
```

## 진행 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1차 기본 연결 | 업로드, 숫자 정렬, 파일명 지정, 수동 배치, 곱하기, 저장·불러오기, PNG 출력 | ✅ 프로토타입 (11/19) |
| 2차 배치 기반 배열 | 도곽 모서리 지정(자르기·기울기·배율 자동) ✅ / 이웃 번호·배치표 입력 → 자동 배열 | 진행 중 (11/26) |
| 3차 배치도 인식 | 배치도 격자 자동 인식 + 번호 확인 | 예정 |
| 4차 정렬·성능 | 기준점 2쌍 정렬, 기울기·배율 보정 | 예정 |
